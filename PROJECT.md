# Мастер рядом

Карточка проекта для агентов-ролей. Источники правды и подробности: [AGENTS.md](./AGENTS.md), [README.md](./README.md), [docs/product/](./docs/product/README.md), [POSTGRESQL_SETUP.md](./POSTGRESQL_SETUP.md), [PRISMA_USAGE.md](./PRISMA_USAGE.md). ## Продукт
- Что это: сервис вызова локальных бытовых мастеров. Клиент создаёт заказ, получает до трёх предложений подходящих мастеров и выбирает исполнителя.
- Для кого: городской житель, которому нужно безопасно и предсказуемо решить бытовую проблему дома ([стратегия](./docs/product/02-product-strategy.md)). Proto-persona «Анна, организатор дома» пока гипотеза.
- Главная ценность: короткий объяснимый выбор из трёх проверенных мастеров с понятной ценой, временем приезда и надёжностью. Обещание: «Три подходящих мастера. Понятная цена. Подтверждённый результат.»
- Роли:
  - клиент создаёт заказ, сравнивает до трёх предложений, выбирает мастера, принимает работу и оставляет отзыв;
  - мастер настраивает категории и районы, отправляет предложение и ведёт назначенный заказ;
  - администратор верифицирует мастеров вручную, работает с пользователями, заказами, категориями, жалобами и спорами.
- Неизменяемые правила продукта (из AGENTS.md и стратегии):
  - точный адрес клиента скрыт, пока мастер не выбран и не подтвердил заказ;
  - отзывы привязаны только к завершённым заказам;
  - нет платного ранжирования, продажи мест в выдаче, платы за отклик и покупки лидов;
  - изменение цены после выезда только с явного согласия клиента;
  - интерфейс не выдаёт прототип за работающую функцию (см. раздел «Правдивость» в AGENTS.md).
- North Star: подтверждённые завершённые заказы в неделю.

## Стек и окружение
- Фреймворк / язык: Next.js 16 (App Router, Server Actions), React 19, TypeScript strict, Zod, bcryptjs, Lucide React.
- База данных: текущий runtime — `better-sqlite3`, файл в `.data/` (не коммитится). Prisma + PostgreSQL подготовлены, переход не завершён; постоянный dual-write запрещён. Прод трогает только владелец; миграции — в `scripts/migrations/`.
- Медиа: фото заказов, работ и документы мастеров сейчас хранятся в базе. Документы личности и фото клиентов — чувствительные данные.
- Продакшен URL: ВОПРОС к владельцу.
- Превью: Vercel preview на каждую ветку — ВОПРОС, подключён ли Vercel. На архивной ветке `codex/feat-postgres-cutover` есть код под Vercel + Neon; в `main` его нет.
- Node.js 22+, npm 10+.
- Команды:
  - `npm run dev` — локальный сервер;
  - `npm run build` / `npm run start` — продакшен-сборка и запуск;
  - `npx next typegen && npm run typecheck` — типы (typegen нужен на чистой копии);
  - `npm run lint` — ESLint;
  - `npm test` — доменные тесты (`tsx --test`, SQLite во временных файлах `.data/`);
  - `npm run seed` — демо-данные (пароль демо-аккаунтов в README).
- Перед каждым push (AGENTS.md): lint, typecheck, test, build, `git diff --check`.

### Переменные окружения
Значения не хранятся в репозитории. Секретов текущий runtime не требует.

| Переменная | По умолчанию | Назначение |
| --- | --- | --- |
| `DATABASE_FILENAME` | `master-ryadom.db` | SQLite-файл в `.data/` |
| `DATABASE_URL` | нет | PostgreSQL, только для подготовленного перехода |
| `SESSION_TTL_DAYS` | `7` | Срок жизни сессии |
| `URGENCY_MULTIPLIER` | `2` | Коэффициент срочного заказа, 1–5 |
| `NORMAL_MATCH_TTL_MINUTES` | `120` | Поиск мастеров для обычного заказа |
| `URGENT_MATCH_TTL_MINUTES` | `45` | Поиск мастеров для срочного заказа |
| `MASTER_OFFER_TTL_MINUTES` | `20` | Время жизни предложения мастера |
| `WARRANTY_DEFAULT_DAYS` | `30` | Срок гарантии после завершения, 1–365 (нет в README) |
